A single sentence about the best advice I ever received, written to `entry.txt` by `main.ts`.

> My grandmother said: never trust a Wi-Fi network named 'Free', and never trust a man who says 'trust me'.

## Run

```sh
node main.ts
```

`main.ts` reads `entry.txt` and writes it to the output directory given by
`MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`, else `./output`) as `entry.txt`.
Node 22+, standard library only — no network, no wall clock.
